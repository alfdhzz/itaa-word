# A Little World of Itaa

Website statis menggunakan HTML, Tailwind CSS (CDN), CSS, dan JavaScript.

## Menjalankan
1. Ekstrak folder `itaa-website`.
2. Buka `index.html` di browser, atau jalankan Live Server dari VS Code.
3. Pastikan koneksi internet aktif untuk memuat Tailwind CDN dan Google Fonts.

## Mengganti foto
Ganti file di `assets/images/` dengan foto pilihan, lalu sesuaikan nama file di `index.html` jika diperlukan.

## Mengubah konten
Edit teks di `index.html`. Bagian favorit dan pesan surat masih berupa contoh dan bisa disesuaikan.

Catatan: Tailwind dimuat melalui CDN agar mudah dicoba. Untuk deployment produksi, Tailwind sebaiknya dibangun menjadi file CSS lokal.
